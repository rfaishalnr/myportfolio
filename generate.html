Buka halaman ini via http://localhost:8787/generate.html (bukan file://). Klik generate, tunggu selesai, lalu simpan ke assets/downloads/.

Cara Pakai

  1. Pastikan server lokal sudah berjalan (jalankan python -m http.server 8787)
  2. Buka http://localhost:8787/generate.html di Chrome/Edge
  3. Klik Generate PDF, tunggu selesai, simpan file ke assets/downloads/
  4. Klik Generate PPT, tunggu selesai, simpan file ke assets/downloads/
  5. Nama file harus persis: Faishal Nizaar Rizq - Portfolio.pdf dan Faishal Nizaar Rizq - Portfolio.pptx
